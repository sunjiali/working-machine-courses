# Working Machine 交互课

把问题做成一台能点的机器：拆开 · 看懂 · 搞坏它。

- **服务器硬件课**（根路径）：2U 机架服务器的 3D 交互课——6 步开机导览、6 节课、搞坏它实验室（负载/室温/风扇故障/断电）、RAID 5 拔盘模拟、分解视图。所有读数由同一个纯函数模型 `machineModel` 实时计算。
- **继电器元件课**（`/relay/`）：一个继电器内部的因果链——小电流 → 磁场 → 衔铁 → 触点 → 大电流负载；含触点粘连、线圈烧断、弹簧疲劳三种故障实验与互动题。

两件产品均为单文件 HTML（含本地打包的 three.js），无后端、无构建步骤，静态托管即可运行。
